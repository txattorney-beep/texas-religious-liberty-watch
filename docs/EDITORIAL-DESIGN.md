# Liberty Watch editorial design

The November 2026 presentation uses the existing maroon (#660000), gold (#F4AA00), and parchment (#F4EAD7) palette. A book-and-light line emblem, serif masthead, numbered sections, ruled lists, and responsive three-column phone navigation establish a publication identity across the tracker, news, hearings, rulings, and biography pages.

The shared editorial.css is loaded last by dist/index.html and inherited by scripts/build_pages.py. Keep its version in the /90r/ service worker CORE list synchronized when changing it. Existing tracking data, source labeling, analytics, biography, and search behavior are preserved.
